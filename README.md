# DioMasteR GOLD AI

Android demo app for XAUUSD (gold), Greek interface, black-and-gold design, and a virtual $10,000 account.

## Safety
Paper Trading only. No broker connection, no API keys, and no real orders. Any displayed quote in the first demo build is simulated, not a live market price. MT5 demo integration and verified live market data are future phases.

## Build
Run `gradle assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.
